# Spotlight

## What does it even do?
Spotlight is an [MQTT](https://learn.sparkfun.com/tutorials/introduction-to-mqtt/all) activated semi-high power LED (3.3-3.6V @715mA). It connects to MQTT Brokers (stay tuned for an MQTT discord bot!!) and uses the signal recieved to enable a PWM output to the LED. If I get it working correctly then there will be an enclosure with a way to focus the beam and some additional lenses to project imagery onto your wall or ceiling (think Bat-Signal). There are no physical inputs on the device so this is not a lamp.
